# A B 개별 단면과 종합 판단 수정 계획

원본 PERIODIC 및 EVIDENCE는 유지한다. 서로 다른 측정 평면에 대한 공통 bin 융합을 제거하고 센서별 단면을 계산한다.

## 설계

- 센서별 section 설정에 sensor_id, 단면 축·원점, bin 폭·바닥·상한·마스크, 필터와 보간 한도를 둔다.
- 반사점은 센서별 검증 R/t로 실수 좌표를 계산한다. 센서 평면은 R의 세 번째 열을 법선으로 사용한다. 단면 축은 그 평면의 수평 방향이어야 하며 기울어진 평면도 허용한다.
- 각 센서 안에서만 bin 중앙값·공간 이상점 제거·시간 중앙값·제한 보간을 수행한다. 다른 센서의 점으로 빈 bin을 채우거나 높이를 평균하지 않는다.
- 면적은 단면의 수평 폭과 수직 높이를 사용한 수직 투영 면적임을 출력한다. A/B 면적비는 개별 값이며 전체 용기의 부피율로 간주하지 않는다.
- 종합은 각 독립 단면의 최신 기준 시각 정합과 유효성 확인 후 검증된 센서별 보정곡선 및 명시적 양의 가중치로 수행한다. 가중치 합은 1이다. 기본 곡선·가중치를 주지 않는다.
- 한 센서 누락/만료/미검증/평면 불일치 시 그 센서 단면 상태를 구분한다. 다른 정상 단면은 유지하지만 종합 값은 null이다. 서로 다른 단면의 높이 차이는 SENSOR_DISAGREEMENT가 아니다.
- 기존 공통 단면 설정은 등록 호환만 유지하며 수치 판단은 LEGACY_SECTION_MODEL_UNSUPPORTED로 보류한다.
- 출력은 section_profiles의 센서별 상태·단면과 fusion_result의 입력 면적비·보정값·가중치·최종값으로 분리한다. 근거 저장 보호와 독립 전송은 유지한다.
